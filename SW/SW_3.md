## Задача 1 (SW_3)

**tags:** SW_3, BO_1

**темы:** битовые операции

**файлы**: bit_operations.*

---

Написать функцию, которая выполняет циклический сдвиг всех чисел в массиве размера $size$ на $N$ бит влево/вправо.

---

### Прототип функции

```cpp
void cycleShiftArray(int* array, int size, int N, bool left);
```

### Аргументы

- *array* - указатель на нулевой элемент массива
- *size* - размер массива
- *N* - сдвиг на N разрядов
- *left* - если $true$ -- влево, иначе вправо

### Пример работы

```cpp
{
	int ar[4] = {0x40, 0x00, 0x80, 0x01};
	cycleShiftArray(ar, 4, 1); //< 0x80, 0x00, 0x100, 0x02
}
{
	int ar[4] = {0x80000001, 0x00, 0x80, 0x10};
	cycleShiftArray(ar, 4, 1); //< 0x02, 0x00, 0x100, 0x21
}
```

## Задача 2

**tags:** SW_3, BO_2

**темы:** битовые операции

**файлы**: bit_operations.*

---

Написать функцию установки единичного бита в числе, и функцию установки нулевого бита в числе.

---

### Прототип функции

```cpp
	void setBit(int* number, int numBit); //< функция установки 1 в числе
	void clearBit(int* number, int numBit); //< функция установки 0 в числе
```

### Аргументы

- *number* - адрес числа, в котором выполняется установка/сброс 1
- *numBit* - номер бита в котором должна быть установлена 1/0

### Пример работы

```cpp
{
	int number = 0x0F;
	setBit(&number, 8); //< number == 0x10F
	clearBit(&number, 1); //< number == 0x10D
}
```

## Задача 3

**tags:** SW_3, FO_1

**темы:** файловые операции

**файлы**: file_operations.*

---

Написать функцию записи элементов массива в файл. При этом задаётся число столбцов, знак разделителя чисел, максимальный/минимальный элемент массива и число элементов.

---

### Прототип функции

```cpp
void fillFile(const char* fileName, int min, int max, char delimeter, int cols, int countElements);
```

### Аргументы

- *fileName* - имя файла
- *min* - минимальный элемент
- *max* - максимальный элемент
- *delimeter* - разделитель
- *cols* - число колонок
- *countElements* - число элементов

### Пример работы

```cpp
fillFile("test", 10, 20, '\t', 4, 12);
```

результат работы (как пример)

| 10  | \t  | 15  | \t  | 20  | \t  | 19  | \n  |
| :-: | :-: | :-: | :-: | :-: | :-: | :-: | :-: |
| 16  | \t  | 10  | \t  | 18  | \t  | 15  | \n  |
| 15  | \t  | 18  | \t  | 11  | \t  | 18  | \n  |
