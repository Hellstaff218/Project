## Задача 1

**tags**: SW_1_1

--------

Реализовать сортировку вставками с возможностью задавать сортировку по возрастанию или по убыванию.

---

### Прототип функции

```cpp
void selectionSort(int* ar, unsigned int size, bool ascending);
```

### Аргументы

- `ar` - указатель на массив
- `size` - размер массива
- `ascending` - если *true* $\rightarrow$ сортировать по возрастанию, иначе по убыванию

### Пример работы

```cpp
int ar[] = {1,2,6,3,5};
selectionSort(ar, 5, true); // после выполнения ar[] = 1,2,3,5,6
selectionSort(ar, 5, false); // после выполнения ar[] = 6,5,3,2,1
```

## Задача 2

**tags:**  SW_1_2

---

Написать функцию для проверки массива на отсортированность.

---

### Прототип функции

```cpp
int isSorted(const int* array, unsigned int size);
```

### Аргументы

- `array` - массив
- `size` - размер массива

### Функция возвращает

- `0` - не отсортирован
- `1` - отсортирован по возрастанию
- `-1` - отсортирован по убыванию

### Пример работы

```cpp
int ar1[] = {1,2,3,4,5};
int ar2[] = {5,4,3,2,1};
int ar3[] = {5,4,3,2,10};
int res = isSorted(ar1, 5); // res -> 1
res = isSorted(ar2, 5); // res -> -1
res = isSorted(ar3, 5); // res -> 0
```
