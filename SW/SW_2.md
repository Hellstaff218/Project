## Задача 1

**tags:** SW_2_1

**темы:** битовые операции

---

Выполнить перестановку полуслов (2 байта) в слове (4 байта). (первые два байта поменять местами со вторыми двумя байтами)

---

### Прототип функции

```cpp
void swapHalfWord(unsigned int* words);
```

### Аргументы

- `words` - слово

### Пример работы

```cpp title:"example 1"
int words = 0xFFAABBCC;
swapHalfWord(&words); //< --> words = 0xBBCCFFAA
```

```c++ title:"example 2"
int words1 = 0x01020304;
swapHalfWord(&words1); //< --> words = 0x03040102
```

## Задача 2

**tags:**  SW_2_2

**темы:** битовые операции

---

Реализовать циклический сдвиг влево/вправо на N разрядов в 32 битном числе.

---

### Прототип функции

```cpp
void cycleShift(int* number, int N, int left);
```

### Аргументы

- `number` - число которое двигаем
- `N` - число разрядов
- `left` - если 1 то влево, если 0 - вправо

### Пример работы

```cpp
int number = 0x00004000;
cycleShift(&number, 1, 0); //<< number = 0x00002000;
cycleShift(&number, 2, 0); //<< number = 0x00000800;
cycleShift(&number, 3, 1); //<< number = 0x00004000;
```

## Задача 3

**tags:**  SW_2_3

**темы:** битовые операции

---

Перебрать элементы массива размера N и найти элемент с самым большим числом единичных битов, при этом, если число отрицательное, то данный элемент в расчёт не брать. 
Функция должна вернуть индекс такого числа, если в массиве таких чисел несколько то функция должна вернуть индекс первого встретившегося.

---

### Прототип функции

```cpp
int getMaxBit(const int* array, int N);
```

### Аргументы

- `array` - массив
- `N` - размер массива

### Функция возвращает

индекс числа соответствующего условию: не отрицательное и с самым большим число единичных бит. Если в массиве все числа отрицательные вернуть -1. 

### Пример работы

```cpp
{
	int* ar[5] = {0xFFFFFFFF, 0xFFFF, 0x00, 0x07F, 0x10101010};
	int index = getMaxBit(ar, 5); //< index = 1
}
{
	int* ar[5] = {-1,-2,-3,-4,-5};
	int index = getMaxBit(ar, 5); //< index = -1
}
```

## Задача 4

**tags:** SW_2_4

**темы:** битовые операции

---

Вернуть число единичных бит в переменной.

---

### Прототип функции

```cpp
unsigned char getCount1Bit(int number);
```

### Аргументы

- `number` - число

### Функция возвращает

число единичных бит в переданном числе `number`

### Пример работы

```cpp
int res = getCount1Bit(10); //res = 2
res = getCount1Bit(1000); //res = 6
```
