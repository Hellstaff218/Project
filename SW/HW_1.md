Реализовать функции сортировок (можно брать уже ранее реализованные, только необходимо разобраться в алгоритмах их работы):
1. пузырьковая сортировка;
2. сортировка выбором;
3. сортировка вставками;
4. сортировка слиянием;
5. быстрая сортировка (сортировка Хоара);
6. сортировка Шелла;
7. сортировка подсчётом.

Оценить длительность каждой функции сортировки на различных размерах массивов. Размер массива изменять от 10 до 5000000 элементов с переменным шагом. Измеренное время записать в файл в следующем формате (время измерять в мс, записывать в файл с точностью до 2 знаков после запятой): 

| кол-во<br>элементов | пузырьковая <br>сортировка | сортировка <br>выбором | сортировка<br>вставками | сортировка <br>слиянием | быстрая <br>сортировка | сортировка <br>Шелла | сортировка<br>подсчётом |
| :-----------------: | :------------------------: | :--------------------: | :---------------------: | :---------------------: | :--------------------: | :------------------: | :---------------------: |
|         10          |         \[время\]          |       \[время\]        |        \[время\]        |        \[время\]        |       \[время\]        |      \[время\]       |        \[время\]        |
|         50          |         \[время\]          |       \[время\]        |        \[время\]        |        \[время\]        |       \[время\]        |      \[время\]       |        \[время\]        |
|         ...         |                            |                        |                         |                         |                        |                      |                         |
|       5000000       |            ---             |          ---           |           ---           |        \[время\]        |       \[время\]        |         ---          |        \[время\]        |

Если вероятное время сортировки может превысить указанное время (это время задаётся при запуске программы), то эту функцию сортировки в дальнейшем не использовать и в файл записывать "---".
Максимальное ограничение времени сортировки задаётся с помощью флага `--max_time`, после которого указывается максимальное время сортировки в миллисекундах.

Программа может быть вызвана следующим образом: `./a.out --mat_time 2000`, результаты оценок длительности сортировок должны быть записаны в файл для всех сортировок и возможных размеров массивов, время сортировки которых не превышает 2 сек. Если программа вызвана без этого флага, то время работы функции сортировки по умолчанию ограничено до 1 сек.
Необходимо предусмотреть возможность задания минимального/максимального размера и шага его изменения с помощью флагов:
- `--min_size` минимальный размер массива
- `--max_size` максимальный размер массива
- `--step_size` шаг изменения размера массива

### Прототипы функций сортировок (реализовать в файле sorts.cpp)

```cpp title:"Функции сортировок"
	void bubbleSort(int* ar, int size, bool (*comp)(int, int));  //< пузырьковая сортировка
	void selectionSort(int* ar, int size, bool (*comp)(int,int));//< сортировка выбором
	void insertionSort(int* ar, int size, bool (*comp)(int,int));//< сортировка вставками
	void mergeSort(int* ar, int size, bool (*comp)(int,int));    //< сортировка слиянием
	void quickSort(int* ar, int size, bool (*comp)(int,int));    //< быстрая сортировка
	void sortShell(int* ar, int size, bool (*comp)(int,int));    //< сортировка Шелла
	void countSort(int* ar, int size, bool (*comp)(int,int));    //< сортировка подсчётом
```

Аргументы для сортировок:
- `ar` - массив
- `size` - размер массива
- `bool (*comp)(int,int);` - функция компаратор

- `size` - размер этого массива

### Рекомендации

для оценки времени выполнения функции рекомендуется использовать библиотеку `chrono`, более подробно см. [статья Habr](https://habr.com/ru/companies/otus/articles/864900/)

```cpp title:"Пример измерения длительности"
#include <iostream>
#include <chrono>

void foo() {
	//функция выполняется длительное время
}

int main() {
	auto start = std::chrono::high_resolution_clock::now();
	foo();	
	auto end = std::chrono::high_resolution_clock::now();
	std::chrono::duration<double, std::milli> elapsed = end - start;
	std::cout << "time = " << elapsed.count() << std::endl;
	return 0;	
}
```

- `std::pico` - результат измерений будет представлен в пикосекундах ($10^{-12}$)
- `std::nano`- результат измерений будет представлен в наносекундах($10^{-9}$)
- `std::micro` - результат измерений будет представлен в микросекундах ($10^{-6}$)
- `std::milii` - результат измерений будет представлен в миллисекундах ($10^{-3}$)

см. подробнее в [std::ratio](https://en.cppreference.com/w/cpp/numeric/ratio/ratio.html)
